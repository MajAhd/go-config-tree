# Contributing to go-config-tree

First off, thank you for considering contributing to `go-config-tree`! It's people like you that make open source such a great community.

## How to Contribute

1. **Fork the Repository**: Fork the project on GitHub and clone your fork locally.
2. **Create a Branch**: Create a descriptive branch for your changes (`git checkout -b feature/amazing-feature`).
3. **Make your Changes**: Implement your feature or bug fix.
4. **Run Tests and Linter**: Ensure your code is clean and passes all tests.
   ```bash
   make lint
   make test
   make format
   ```
5. **Commit your Changes**: Use clear and descriptive commit messages.
6. **Push and Pull Request**: Push your branch to your fork and submit a Pull Request against the `main` branch of the original repository.

## Reporting Bugs

If you find a bug, please create an issue on GitHub detailing the problem, your environment, and steps to reproduce it.

## Suggesting Enhancements

I'm always looking for ways to improve! If you have an idea, feel free to open an issue labeled `enhancement` to discuss it before you start writing code.
